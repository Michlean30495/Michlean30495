## Jak poruszać się po repozytoriach

- **README w repozytorium** opisuje temat, strukturę katalogów, technologie i sposób rozpoczęcia pracy.
- **Topics** pozwalają odróżnić `university-exercises` od `exam-preparation`; projekt Python ma etykiety `python`, `tkinter` i `hangman`.
- **Nazwy repozytoriów** zachowują oryginalne oznaczenia ćwiczeń i kolokwiów.
